# Mewgenics-SMW-GFX-Hack
This is a hack that adds some of my custom sprites to SMW. In Order to enjoy my hacks fully. you must have the SMW hacking basics, like ASAR, Lunar Magic, And IBS.
Lunar magic to Apply the GFX files to the ROM. And ASAR to patch stuff (1 thing really.) and IBS to apply BPS files to your SMW ROM.

In Order to do all of this you must have a ROM ofc. For Lunar magic For Applying the GFX files, Open your ROM in lunar magic click the red mushroom, go to your newly created graphics folder. replace all the gfx files with mines, and click on the green mushroom!  For Asar you must save both the overworld a level, Asar takes .asm files btw, and after you're done open Asar and it should bring up a command box, just do what it says.   IBS is self explanatory.
